# Tech stack

Main components of the combined supplier dashboard and production planner.
`package-lock.json` is the canonical JavaScript dependency record; use
`npm ci`. Python dependencies are in `deep-research-agent/requirements.txt`.
The retained `bun.lock` comes from the incoming template and is not the team
installation path. Exact resolved JavaScript versions belong to the npm lockfile.

## External APIs and services

| Service | Used by | Purpose |
|---|---|---|
| [Nebius Token Factory](https://tokenfactory.nebius.com) | `deep-research-agent` | OpenAI-compatible inference API hosting the reasoning model **`MiniMaxAI/MiniMax-M3`**, which plans the research, reads search results and produces scores, reasons and reports. Endpoint `https://api.tokenfactory.nebius.com/v1`, key `NEBIUS_API_KEY`. |
| [Tavily Search API](https://tavily.com) | `deep-research-agent` | Web search built for LLM agents. Called with `search_depth="advanced"` and `max_results=5`; returns the pages and URLs that the reports cite. Key `TAVILY_API_KEY`. |
| [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) | `server/assistant.ts` | Optional production-planning explanations and suggestions; `OPENAI_API_KEY` and `OPENAI_MODEL`, independently configured from supplier AI. |
| [OpenFreeMap](https://openfreemap.org) | Shared map proxy | Public map styles, fonts and tiles for supplier, production and recovery maps; requires network access. |
| [Open-Meteo](https://open-meteo.com) | `/api/climate` | Public historical weather data for climate summaries. |
| Redis | `lib/cache.ts` | Optional cache via `REDIS_URL`; otherwise memory in the current server process. |

Bundled supplier browsing and deterministic planning need no provider keys.
Map and climate features need network access. Optional AI features need
only their own provider configuration.

## Data layer

| Package | Version | Purpose |
|---|---|---|
| [DuckDB](https://duckdb.org) (`@duckdb/node-api`) | 1.5.6-r.1 | Embedded SQL engine; queries the dataset CSV and the agent's output CSV in-process |
| [zod](https://zod.dev) | 4.6.7 | Runtime validation of supplier rows and of analyst answer blocks |

Data files: `data/supplier_risk_dataset.csv` (10,000 anonymized suppliers,
provided for the hackathon) and `data/risk_criteria_description.md` (column
definitions).

The production planning engine is application TypeScript in `src/lib/`.
It compares three predefined alternatives without a separate optimization
service. Confirmation snapshots and simulated inputs persist in browser local
storage. Supplier research uses local CSV output. Dataset analyst questions
use `data/suppliers.duckdb`, generated by `scripts/create_duckdb.py`; Python's
DuckDB dependency is included in the agent requirements.
